Implementation in this separate experiment copy
------------------------------------------------
1. Configurable four-update critic bursts every 16 vector collection steps,
   after the first outer round initializes the critic. Only current-reference,
   current-outer-generation training transitions with valid successors qualify.
   At least two minibatches of recent evidence are required. Reference changes
   clear replay and force fresh collection. The dedicated RNG does not consume
   the actor/proposal random stream. No actor updates or new simulations are
   triggered by these bursts. Existing outer-round fitting is retained.
   Set critic_online_interval_vector_steps=0 for the control configuration.

2. Capture complete baseline/control/candidate trajectories before fitting.
   Save per-frame observations, actions, physical support costs, exact finite-
   horizon discounted returns, and predictions. Also save frozen critic weights
   before each proposal. This makes future audits reproducible.

3. At matched physical adaptation checkpoints, score candidate and no-edit
   trajectories with the same frozen critic and identical frame coverage. Log
   predicted and measured support-return gains, gain error and sign agreement.
   These checks evaluate realized trajectories. They are not a numerical test
   of the fixed-state proposal hypergradient. No acceptance rule is relaxed.

Each uses budgets 135,168 / 200,704 / 266,240 transitions: 532,480 total additional

It uses one scheduler-owned GPU and has a two-hour hard limit. Historical data
are mounted read-only. It does not test main-training schedule performance.

Interpretation and next decision
--------------------------------
The online schedule is a tested implementation for an ablation, not a validated
performance improvement. Assisted TD targets may still be a poor guide to
unassisted behavior, and fitting more often can overfit. The local actor inputs,
network shapes, support objective, and physical acceptance remain unchanged so
the critic schedule can be tested independently. No larger actor is introduced
before measuring whether the existing cost model predicts useful directions.
An actor-context expansion and a matched-compute schedule ablation remain
separate follow-up experiments. CPU tests do not substitute for physical results.
