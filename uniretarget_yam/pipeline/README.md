# UniRetarget YAM pipeline

Snapshot of the scripts that ran the YAM episodes on the yonsei-ai cluster. The solver and training code it drives are in `../code` and `../flash_chord`.

## Layout

- `pipe/`: Slurm scripts for the whole run. `pilot.sh N` searches for a grasp, then trains, scores and renders one episode. `rs.sh` trains an episode with and without VOC.
- `pipe/diag/`: checks and one-off diagnostics. `hold_check.py` reports whether a hand really held its object.
- `comparison/`: scoring and clip recording, bound as `/cmp` in the container.
- `ik/`: Mink IK and HaWoR conversion, from the run directory `latest_recon/run37`.
- `hawor/`: HaWoR rerun with the true camera.
- `data/`: table fits per episode and mesh checks.

## Not in this repository

Copy these to the new server, or rebuild them:

- `flash_chord_yam.sif` and `robotic-grounding-mink-1.3.0.sif` (containers)
- `uniretarget_yam/episodes` and `uniretarget_yam/objects` (generated by `prepare_recon.py`)
- `hawor_rerun/root` (hand results, targets and bundles)
- `source_meshes/public` and `source_meshes/registered` (scanned meshes)
- `source_videos/ego_cam_a` (source videos)
- `latest_recon/run37/rg` and `pydeps` (needed by `ik/yam_mink.py`)
- HaWoR and MANO, for rerunning hand reconstruction

## Before running on another server

The scripts use absolute paths and this cluster's Slurm settings. Change these first:

- `/scratch2/exaFLOPs/...` and `/lustre/exaflops/...` paths in `pipe/`, `comparison/` and `pipe/diag/`, plus `source_meshes` in `../code/prepare_recon.py`
- Slurm partitions, QOS names and GPU types in `pipe/*.sbatch` and `pipe/*.sh`
- Location of `ik/` and `comparison/`: the scripts expect `latest_recon/run37` and `srl_yam_run/comparison`

## Method settings

- Pass: at least 15/16 test worlds for every object on both scoring runs, with VOC off.
- VOC by time: `CURR=yam_voc_50m`. VOC by progress: `VOCARGS=+adaptive_voc.mode=progress`.
- `+training.optimization.residual_penalty` defaults to 1 in `train.sbatch` and `train_a.sbatch`.
- This snapshot has run on the listed episodes only, and has not yet been run from a fresh clone.
